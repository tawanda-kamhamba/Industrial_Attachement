D.1 Purpose of this appendix

This appendix supports Chapter 5 (Results and Testing) and Section 1.6 (Ethical Considerations). It provides the documents used when volunteer participants tested IAMS during user acceptance testing (UAT). Test accounts used fictitious or anonymised data only; no real student grades or confidential institutional records were stored permanently for the test sessions.

D.4 UAT task scripts

The facilitator (researcher) reads the role introduction, then asks the participant to complete each task while observing whether the expected result occurs. Tick Pass or Fail on the record sheet (Section D.5).

Test environment: IAMS web application — e.g. http://localhost/iasms/app/ or hosted demo URL. Browser: Chrome, Edge, or Firefox recommended.

D.4.1 Student role — task script

StepInstruction to participantExpected result
U1Log in using the test index number and password provided.Login succeeds; student dashboard or onboarding (instructions) page appears.
U2Read the Instructions page, then complete Register and Assumption of duty with the sample details given.All main menus unlock (e-logbook, contract, report, visit schedule, etc.).
U3Open E-Logbook and submit one week of entries (sample text is fine).Success message; entry saved and visible when page is refreshed.
U4Upload a sample Contract (PDF file provided by facilitator).File appears as submitted; status shows pending (or similar).
U5Upload a sample Final report (PDF/DOC/DOCX). Try uploading a second file if instructed.First upload succeeds; system prevents duplicate submission (submit-once policy).
U6Open Visit schedule after the supervisor has published dates. Select one available date.Selection is saved; confirmation shown; supervisor can see your name on that date.

D.4.2 Institutional supervisor role — task script

StepInstruction to participantExpected result
U7Log in with test staff ID and password. Open Visit schedule, add one or more dates, and Publish.Dates appear as published; assigned students receive in-system notification.
U8Open Scores (or grade form) for a test student. Enter marks for Visit 1 and Visit 2.Scores save successfully; visible on supervisor and admin score views.
U9Open a student Logbook, add a short comment, and save.Comment saved; student receives in-system notification.

D.4.3 Administrator role — task script

StepInstruction to participantExpected result
U10Log in as administrator. Open the Dashboard and review the statistics and charts.Charts and counts load and match test data in the system.
U11Open Assign supervisors. Link one test student to one test institutional supervisor (or confirm existing link).Assignment saves; student sees supervisor on dashboard where applicable.

D.4.4 Company supervisor role — task script

StepInstruction to participantExpected result
U12On the student portal URL, open the Company supervisor assessment link. Enter the password given by the institutional supervisor. Complete and submit the grade form for the test student.Submission succeeds; grade visible to institutional supervisor and administrator.
